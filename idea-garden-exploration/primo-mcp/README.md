# primo-mcp

> **Status: exploration and testing only.** Not production-ready and not for patron use.

## About this project

This is a personal learning project for building a read-only MCP (Model Context Protocol) server that searches a library catalogue (Ex Libris Primo) from an AI assistant.

It follows a step-by-step guide generated by Claude (Anthropic), based on my prompts and Claude's deep research tool. Parts of the code and guide have not been fully verified, so expect rough edges.

## What to expect

- Early, changing code and structure
- Test data and mock services in place of live systems
- No support, security, or accuracy guarantees

## Getting started

If you'd like to try this out or build on it, here's how to run it locally.

### Requirements

- Python 3.12 or newer
- Node.js (only needed for `mcp dev`, which launches the MCP Inspector through `npx`)

### Check for Python

Before installing, check whether Python 3.12+ is already on your machine:

```bash
python3 --version        # Windows: py --version
```

If you see `Python 3.12.x` or higher, skip ahead to [Install](#install). If the command isn't found, or the version is older than 3.12, install Python using one of the options below.

**Option 1: python.org installer (works on macOS and Windows)**

Download the latest stable release from [python.org/downloads](https://www.python.org/downloads/).

- **macOS:** run the `.pkg` installer.
- **Windows:** use the Python install manager (listed first on the download page), or the standalone `.exe` installer. If you use the standalone installer, tick **"Add python.exe to PATH"**.

**Option 2: uv (macOS, Windows, and Linux)**

[Install uv](https://docs.astral.sh/uv/getting-started/installation/), then run:

```bash
uv python install
```

This installs the latest Python. uv can also manage the environment for this project; see [Using uv](#using-uv-optional) below.

**Linux:** python.org only offers source code for Linux, so use your distribution's package manager (for example `sudo apt install python3 python3-venv` on Debian/Ubuntu) or Option 2. Make sure the version it installs is 3.12 or newer.

After installing, open a new terminal window and re-run the version check.

### Install

From the project folder:

```bash
# Create and activate a virtual environment
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# Install the project and its dependencies (reads pyproject.toml)
pip install -e .
```

The `-e` flag installs in editable mode, so changes to `server.py` take effect without reinstalling.

### Run

```bash
# Open the MCP Inspector in your browser to try the search_books tool
mcp dev server.py

# Or run the server directly (it waits for an MCP client over stdio)
python server.py
```

`mcp dev` is the easier way to check that the tool works. The server currently searches a small list of made-up books, not a live catalogue.

### Using uv (optional)

If you already use [uv](https://docs.astral.sh/uv/), you can skip the steps above. `uv sync` creates the environment from the pinned versions in `uv.lock`, and `uv run mcp dev server.py` starts the Inspector. pip users can ignore `uv.lock`.
