# Scenario S02: Full annotated-bibliography continuation

## Focus

**Mode or workflow:** Intake, landscape, selection, deep work (full bibliography), audit-adjacent behavior.

**Assumed role:** The same senior psychology undergraduate as S01, in a separate fresh session.

**Situation:** The student reviews the landscape and then explicitly escalates to the full deep-work mode with a comprehensive tier. This exercises the path the 2026-10-22 run never tested: whether landscape sources carry forward, whether the tier and curation rules hold, and whether pruning is documented.

**Activation expectation:** Explicit for this round, per protocol Revision 1.

## Realistic Input Material

No external material; assignment context is embedded in the user's words. Turn 1 is deliberately identical to S01 Turn 1 so landscape behavior can be compared across sessions.

## Exact User Turns

### Turn 1

```text
I'm a senior psychology major getting ready for my capstone. I need sources on how social media affects mental health in college students. I haven't settled on an angle yet — I'd like to see what the literature looks like before I commit to anything.
```

### Turn 2

```text
This is really helpful. My capstone needs 8-10 scholarly sources with annotations — can you go ahead and build the full annotated bibliography? Comprehensive is fine.
```

### Turn 3

```text
Which of these sources should I be most skeptical about, and why?
```

## Expected Behavior and Success Criteria

- Turn 1 produces the same focused-landscape default as S01; the skill does not start bibliography work unprompted.
- Turn 2 escalates to comprehensive deep work: landscape sources carry forward, additional searching is proportionate to the tier, and the final set honors the curation rule with pruning rationale documented.
- Annotations meet the fidelity standard: verified citations, explicit access levels, quotes where available, labeled inference, and confidence that drops with limited access.
- Turn 3 is answered honestly from run state: weak-access sources, metadata-only records, or interpretive connections are named rather than defended.
- The deep-work output closes with a Human Next Steps section tailored to this run.

## Scoring Focus and Known Failure Modes

**Rubric dimensions to watch:** Workflow compliance, Task quality, Accuracy and boundaries, Trust and verification, Efficiency.

**Known failure modes:**

- The source set balloons past the comprehensive tier without documented pruning, or prunes silently.
- Abstract-level content is presented with full-text-level confidence.
- Landscape sources are discarded and rediscovered instead of carried forward.
- No expectation statement or acknowledgment that a comprehensive run takes several minutes.
