# Scenario S01: Clarity rerun (round 2)

Adapted from `2026-11-24-automated-round1/scenarios/S01-narrowing-turn.md`. User turns are verbatim identical to round 1; expected behavior now includes the Plain-Language contract; scoring adds the user-perspective clarity lens from the round 2 protocol.

## Focus

**Mode or workflow:** Intake, landscape (as "overview of the research"), selection, refinement (narrowing), adaptive follow-up.

**Assumed role:** A senior psychology undergraduate preparing a capstone literature review. All clarity judgments are made from this persona's perspective.

**Activation expectation:** Explicit invocation line at Turn 1 (routing deferred, per round-1 decision).

## Exact User Turns

Identical to round 1 S01 (see that card for the verbatim turns).

## Expected Behavior and Success Criteria

Round 1 behaviors must still hold: focused landscape default, proportionate narrowing with source reuse, honest evidence labeling, adaptive turn-3 follow-up, manifest validation.

Plain-language contract (new in this round):

- The landscape response is presented as an "overview of the research," opens by restating the working question, and contains no internal vocabulary.
- Themes appear as headings with theme-phrased questions, two to three representative readings, and a find-more search link.
- Possible directions read as possibilities for the student's research, not proposals or claims about the field.
- Limitations (abstract-level evidence, API counts) appear as consequences with next actions; no API mechanics, no bookkeeping openers.

## Scoring Focus and Known Failure Modes

**Rubric dimensions to watch:** Intake, Workflow compliance, Task quality, Follow-up handling, Accuracy and boundaries, Efficiency, Plain language (user-perspective clarity checklist in the protocol).

**Known failure modes:**

- Old template habits persist (numbered theme list, standalone Questions table, search-log offer, bookkeeping opener, API transparency note).
- The restructured template is followed mechanically but reads stiffer or longer than round 1, hurting clarity.
- Persona confusion: any sentence a psychology undergraduate would have to reread to understand.
