# Library Style Overview

This reference is the skill’s source-hierarchy and uncertainty layer. It distills the local style sources used to build the skill. Use [source-citations.md](source-citations.md) for citation labels and canonical URLs. Use [content-scenarios.md](content-scenarios.md) to route a request to the smallest relevant set of references.

## Source Hierarchy

Apply sources in this order:

1. **UC San Diego Editorial Style Guide and Web Editorial Style Guide** for the AP-based campus baseline, UC San Diego exceptions, inclusive language, links, and general usage.
2. **UX Writing at UC San Diego Library** for Library voice, user-centered transformation, copy sizing, microcopy, jargon, brevity, AI-tell rules, and the draft checklist.
3. **UC San Diego Library Editorial Style Guide** for Library names, locations, services, systems, and terminology. This more specific guide supplements and may supersede campus rules for Library terms.
4. **UC San Diego Brand Voice and Messaging** for tone, emphasis, and messaging approach.
5. **NN/g UX writing research** for the evidence behind scanning, brevity, copy sizes, jargon, and microcopy.

When sources are silent, use professional judgment and label uncertainty. When sources conflict, explain the conflict and choose based on audience, placement, task, and specificity. Do not invent AP rules. If a current AP Stylebook entry is needed, say so and ask the user to verify. Cite sources with the labels and URLs in [source-citations.md](source-citations.md).

## AI-Sounding Language

Remove patterns that make copy algorithmic, vague, or wordy:

- Em dashes when another punctuation mark works as well.
- “Not only X, but also Y” and “X isn’t just about Y.”
- “Leverage,” “utilize,” “empower,” “unlock,” “enable,” “revolutionary,” “game-changing,” “cutting-edge,” and “state-of-the-art.”
- “In today’s rapidly changing world” and similar openers.
- “It could be argued,” “one might consider,” “it is possible that,” “it is important to note that,” and “it’s worth mentioning that.”
- Unnecessary intensifiers such as “very,” “really,” “quite,” “fairly,” and “somewhat.”
- “Let me explain,” “let’s explore,” “let’s break this down,” “remember,” “ultimately,” and “at the end of the day.”

Replace these with direct statements, concrete descriptions, numbers, named examples, and actions the user can take.

## Source Verification

For uncertain campus style questions, prefer `brand.ucsd.edu` and `blink.ucsd.edu/technology/websites/training/writing/styleguide/index.html`. Cite the page used and retrieval date when available. If a rule requires AP Stylebook access or expert confirmation, say so. Distinguish verified source guidance from local assumptions.
