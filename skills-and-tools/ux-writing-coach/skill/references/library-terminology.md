# Library Names and Terminology

Use this reference for exact Library names, locations, programs, systems, collections, and public-facing terminology. If a name is not listed here, verify it with the user or the Library Editorial Style Guide rather than inventing it.

## Library Naming

- Use **UC San Diego Library** on first reference whenever possible. Use “the Library” on later reference after the full name appears.
- Do not use “UCSD Library.”
- Capitalize “the Library” when referring to UC San Diego Library, except that “the” is capitalized only at the start of a sentence.

## Public-Facing Terminology

Prefer the user’s language over internal library vocabulary.

| Use | Avoid in public copy |
| --- | --- |
| books | monographs |
| journals or periodicals | serials |
| course reserves; “reserves” after first use | unexplained “reserves” |
| electronic reserves then “e-reserves” | unexplained “e-reserves” |
| checkout period | loan or borrowing period |
| cardholder | card holder |
| community borrower | unexplained borrower category |
| member of the public | unexplained public borrower category |
| Get Help | LibAnswers or Ask A Librarian |
| limited use | controlled circulation or ConCirc |
| Library Guides or the specific guide title | LibGuides in first public reference |
| full-text | fulltext |
| open access; lowercase except at sentence start or in a name | Open Access in generic use |
| peer-reviewed as an adjective; peer review process as a noun | unexplained peer review jargon |
| pickup as a noun or adjective; pick up as a verb | pick-up |
| Explore magazine | EXPLORE or italicized Explore |

Use “email,” “homepage,” “internet,” “intranet,” and “website” in lowercase except at the start of a sentence. Use “web page” as two words and “Wi-Fi” with a hyphen and capital W.
