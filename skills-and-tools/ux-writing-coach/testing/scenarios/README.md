# Reusable Testing Scenarios

These scenario cards support fresh-session testing in TritonAI. Each card contains the exact user turns and an excerpt that simulates the material the participant would bring to the skill. Do not paste the scenario card itself into the tested session.

| ID | File | Primary mode | Output focus |
| --- | --- | --- | --- |
| A1 | `scenario-01-ask-overview.md` | Intake + drafting | Service overview |
| A2 | `scenario-02-borrow-offering-cards.md` | Drafting + feedback | Service-offering cards |
| A3 | `scenario-03-tech-lending-outage.md` | Feedback + drafting | Status, alert, or help message |
| A4 | `scenario-04-prize-evaluation.md` | Evaluation + intake | Service page assessment |
| A5 | `scenario-05-ask-contact-support.md` | Intake + drafting | Contact and support |
| A6 | `scenario-06-tech-lending-boundary.md` | Combination | Error/help message and scope |
| A7 | `scenario-07-borrow-source-material-plan.md` | Intake + drafting | Source material and working plan |

Use `testing/automated-testing-plan.md` for fresh-session protocol and scoring. Use `testing/human-testing-plan.md` for facilitated Library staff sessions. Use `testing/reports/report-template.md` to record the complete transcript and evaluation notes.
