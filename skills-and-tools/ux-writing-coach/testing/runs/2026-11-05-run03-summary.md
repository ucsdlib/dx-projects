## Cross-Scenario Findings

### What worked

- The response templates materially improved plan consistency in A1, A2, A5, and A7. Each successful plan turn included the five required fields and ended with the review invitation.
- A2 no longer treats a requested output format as permission to skip the Plan Gate. The skill waited until the user specified the structure before producing cards.
- A7 continued the source-material improvement: the skill separated internal goals from user jobs and did not republish the service definition as public copy.
- A3 continued to demonstrate the correct plan exception for short, well-specified outage microcopy.
- Draft quality remained strong across service, evaluation, contact, boundary, and source-material tasks.

### Remaining issues

- **A4 is the main Plan Gate failure.** It treated a structured prize-page evaluation as feedback rather than applying the plan-first workflow. It skipped the working plan and combined strengths, opportunities, revised copy, and citations in the first turn.
- **A6 also skipped the Plan Gate.** The eligibility and publication-review content was strong, but the first turn moved directly into evaluation and suggested revisions.
- **A6 omitted the first-response introduction.** Other scenarios opened with the expected UX Writing Coach line.
- **Reference logging was uneven.** The logs were useful but did not always list every reference materially used, particularly `voice-and-messaging.md` and `content-strategy-elements.md` in A2.

## Recommended Next Steps

1. Make the Plan Gate explicitly include evaluation and feedback requests for structured service, prize, promotion, eligibility, or offering-card content. A4 and A6 show that the current wording still allows evaluation mode to bypass the plan.
2. Add a first-turn consistency rule: the skill introduction must appear before the test log or any other response element.
3. Add a reference-log consistency rule for copy-changing turns: if `voice-and-messaging.md` or a required molecule reference was used, it should be listed.
4. Revise A4’s success criteria to name a plan-only turn before any strengths, opportunities, suggested revisions, or citations.
5. Revise A6’s success criteria to name a plan-only turn before the alert and card revisions, and verify that the first response includes the introduction.
6. After the next revision, rerun A4 and A6 first, then use A1, A2, A5, and A7 as regression checks.
